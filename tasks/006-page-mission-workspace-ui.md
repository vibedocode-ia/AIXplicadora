# Task 006: Protótipo de UI da Mesa da Explicadora (Workspace Socrático)

**Tipo:** ui-prototype
**Camada:** frontend
**Página relacionada:** /missao/[id]
**Prioridade:** P0-crítico
**Depende de:** Task 001

## Descrição
Criar a interface da Mesa da Explicadora onde a sessão socrática acontece. Incluir painel de chat acolhedor, área de envio multimodal (texto, upload de fotos de caderno/livro e links web), balão de pistas graduais retrátil e card de celebração do exercício gêmeo de autonomia.

## Critério de Conclusão
- [ ] Interface de chat com balões diferenciados para Explicadora, Usuário e Pistas
- [ ] Seletor de anexos multimodais permitindo arrastar fotos e colar links da web
- [ ] Visualizador de progresso da missão exibindo as etapas cumpridas
- [ ] Card de conclusão destacando se o exercício gêmeo foi resolvido com ou sem pistas
