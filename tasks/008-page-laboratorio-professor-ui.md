# Task 008: Protótipo de UI do Laboratório Didático do Professor

**Tipo:** ui-prototype
**Camada:** frontend
**Página relacionada:** /professor
**Prioridade:** P1-importante
**Depende de:** Task 001

## Descrição
Construir a interface do Modo Professor para planejamento de aulas ativas. Incluir gerador de analogias conceituais, sequenciador de perguntas socráticas para engajar turmas e antecipador de concepções equivocadas comuns dos estudantes.

## Critério de Conclusão
- [ ] Campo de entrada para tópico da aula, nível dos alunos e objetivo pedagógico
- [ ] Painel de exibição com 3 variações de analogias com limites de aplicação explicados
- [ ] Roteiro de perguntas socráticas sugeridas em formato de etapas de aula
- [ ] Exportação amigável do plano de explicação em texto e PDF
