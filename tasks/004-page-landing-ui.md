# Task 004: Protótipo de UI da Landing Page Institucional

**Tipo:** ui-prototype
**Camada:** frontend
**Página relacionada:** /
**Prioridade:** P0-crítico
**Depende de:** Task 001

## Descrição
Construir a interface visual completa e responsiva da Landing Page em https://aixplicadora.vibedocode.pro/. Incluir Hero institucional com proposta socrática, demonstração ilustrativa do método, seletor de público (Estudante, Pais, Professor), bloco de como funciona e rodapé com FAQ.

## Critério de Conclusão
- [ ] Hero com tipografia de alto impacto e CTA 'Começar agora' responsivo
- [ ] Demonstração visual do fluxo socrático (dúvida -> pergunta -> pista -> autonomia)
- [ ] Seletor interativo de público alternando exemplos entre Estudante, Pais e Professor
- [ ] Design 100% aderente a mobile-first e acessibilidade WCAG
