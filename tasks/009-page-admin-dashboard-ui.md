# Task 009: Protótipo de UI do Painel Super Admin

**Tipo:** ui-prototype
**Camada:** frontend
**Página relacionada:** /admin
**Prioridade:** P0-crítico
**Depende de:** Task 001

## Descrição
Desenvolver a interface administrativa restrita em https://aixplicadora.vibedocode.pro/admin. Incluir tela de login exclusiva do Super Admin, dashboard com cards de telemetria de tokens de IA, volume de missões ativas, tabela de usuários cadastrados e logs de auditoria.

## Critério de Conclusão
- [ ] Tela de login dedicada com aviso de acesso restrito ao Super Admin VibeDoCode
- [ ] Cards de telemetria exibindo consumo de tokens, custo estimado e missões criadas
- [ ] Tabela com paginação e busca de usuários e papéis atribuídos
- [ ] Área de visualização de logs recentes de segurança e eventos críticos
