# Task 005: Protótipo de UI de Cadastro e Login com Termo de Maioridade

**Tipo:** ui-prototype
**Camada:** frontend
**Página relacionada:** /cadastro, /login
**Prioridade:** P0-crítico
**Depende de:** Task 001

## Descrição
Desenvolver as telas de Cadastro e Login com fluxo de onboarding guiado em 3 etapas. Incluir seleção de perfil (Estudante, Pai Educador, Professor), contexto de ensino (Fundamental ao Doutorado) e checkbox mandatório de maioridade/responsável legal.

## Critério de Conclusão
- [ ] Formulário de cadastro em etapas (Perfil, Contexto e Revisão) com validação visual
- [ ] Checkbox de maioridade de 18 anos ou confirmação de gestão pelo responsável legal
- [ ] Formulário de login limpo com opção de alternar visibilidade de senha
- [ ] Feedback visual imediato para campos preenchidos incorretamente
