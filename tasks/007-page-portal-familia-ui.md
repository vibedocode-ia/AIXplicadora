# Task 007: Protótipo de UI do Painel da Família e Modo Pai-Educador

**Tipo:** ui-prototype
**Camada:** frontend
**Página relacionada:** /familia
**Prioridade:** P1-importante
**Depende de:** Task 001

## Descrição
Desenvolver a interface do Painel da Família para pais e responsáveis. Incluir lista de dependentes cadastrados, relatórios de esforço e autonomia (sem expor notas punitivas) e aba do Modo Pai-Educador com roteiros de como ensinar o conteúdo aos filhos em casa.

## Critério de Conclusão
- [ ] Dashboard com cards de métricas de estudo dos dependentes (tempo e autonomia)
- [ ] Visualizador de relatórios com gráficos simples de competências dominadas
- [ ] Aba do Modo Pai-Educador apresentando dicas pedagógicas e analogias práticas
- [ ] Modal para adição de novo dependente com seleção de nível escolar
